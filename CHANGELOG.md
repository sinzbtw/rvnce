# Changelog

## 0.2.0

- Added five customizable presets, light and dark palettes, three local typefaces, and controls for the profile card, avatar, and links.
- Added image, GIF, and H.264 MP4 backgrounds with size limits, a still poster, and playback controls for motion backgrounds.
- Added reusable theme JSON, live appearance editing with reset and undo, and an examples gallery featuring sinz in the Graphic preset.
- Added optional Made with Rvnce credit for new profiles. Migrated profiles keep the credit off.
- Added profile schema v3 and IndexedDB saves with background media, legacy draft recovery, and cross-tab conflict detection.
- Extended standalone exports to include the selected fonts, backgrounds, and local playback code only for motion backgrounds.

## 0.1.0

- Added a responsive bio-page editor with live preview, basic appearance controls, and browser-local drafts.
- Added avatar uploads, ordered links, profile JSON import and export, and a standalone static site ZIP.
- Added the Mira Park sample profile, bilingual usage docs, and CI for formatting, linting, tests, and builds.
